# Mending Rebalance

A Fabric mod that rebalances the Mending enchantment in Minecraft.

## Compatibility

- **Minecraft:** 1.21.x
- **Fabric Loader:** ≥ 0.18.4
- **Fabric API:** Required
- **Java:** 21+

## Build

```bash
./gradlew build
```

The built JAR will be in `build/libs/`.

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) and [Fabric API](https://modrinth.com/mod/fabric-api) for Minecraft 1.21.x.
2. Copy the built `mending_rebalance-<version>.jar` from `build/libs/` to your Minecraft `mods` folder.
3. Launch the game.
